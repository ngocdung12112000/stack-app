Login flow: every backend file, in order

POST /api/v1/auth/login from the gateway to MySQL and Redis and back. Click a card, or use the arrow keys, to step through the flow. Paths are inside stackshop-backend/.

Login publishes no outbox event. Only registration does (UserRegisteredV1). Repository and adapter internals (for example the Redis key names) are not described here, because this page was built from the handler, endpoint and wiring code.
